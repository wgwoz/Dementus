# Dementus
Dementus jest to projekt i prototyp urządzenia służącego do pomocy osobom z chorobami wieku starczego i po wypadkach z funkcjami umysłowo-motorycznymi. Był on realizowany w celu zgłoszenia go do Olimpiady Innowacyjności Technicznej w Mechatronice, gdzie w 2025 roku zajął 2 miejsce. 

Readme będzie stopniowo rozwijane, celem dokumentacji projektu. w międzyczasie zapraszam do dokumentacji w wersji pdf, która była utworzona na cele konkursu.
